# Linux Course Notes 

Personal notes, commands, concepts, and practical examples collected while studying Linux for Pentesters.

The purpose of this repository is to document useful Linux knowledge, with a focus on commands, techniques, and concepts relevant to cybersecurity and penetration testing.

## Topics

This repository will grow as I progress through the course. Topics may include:

- Linux fundamentals
- File and directory management
- Users and permissions
- Processes and services
- Networking
- Bash and command-line utilities
- System enumeration
- Linux security
- Pentesting-related commands and techniques

## Documentation Approach

Basic Linux concepts that I already know will not be documented in detail.

Instead, I will focus on:
- New commands and utilities
- Useful command options and flags
- Commands that are easy to forget
- Practical examples
- Pentesting use cases
- Linux security concepts
- Tips and personal notes

## Objective
Build a personal Linux reference while improving my knowledge of Linux, cybersecurity, and penetration testing.
